# NumPy Practice & Fundamentals

This repository contains Jupyter Notebooks and dataset files dedicated to learning and practicing fundamental NumPy concepts in Python. 

## 📌 Repository Contents

* **`creating_numpy_arrays.ipynb`**: Demonstrates array initialization methods including `np.array()`, `np.zeros()`, `np.ones()`, `np.arange()`, and `np.linspace()`.
* **`inexing_and_slicing.ipynb`**: Covers 1D/2D array indexing, slicing syntax, and Boolean condition filtering.
* **`numpy_basics.ipynb`**: Explores essential mathematical operations, vectorization, and basic statistical functions.
* **`Employee.csv` & `Employee.xlsx`**: Sample datasets used for data loading and array manipulation practice.
